Recherche 3

Draw random maps and score the same values of w on each one with weighted A*. Each map uses its own A* reference at w = 1: a·cost/cost_ref + b·duration/duration_ref + c·memory/memory_ref, with a = 1, b = 1 and c = 0. The global score of a w is the average of those scores. Lower is better. This search does not change the environment grid or move the agent.

Random map search

Obstacles is a percentage of the cells, rounded to the nearest count. Start and goal stay at opposite corners. Leave the seed empty for a new draw, or reuse a seed to repeat the same maps.
