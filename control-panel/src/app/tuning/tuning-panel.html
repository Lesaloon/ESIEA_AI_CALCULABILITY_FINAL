Weighted A* ranks cells by f = g + w·h. Each method below searches for the w that minimizes F = α·time/ref + β·cost/optimal + γ·heap/ref, averaged over a U trap and three random weighted maps. The baseline is classic A* (w = 1), whose F is about α + β + γ.

Tuning configuration

Size 10–40, w max 2–100, start between 1 and w max. Leave the cost limit empty for no constraint; a run violating it is penalized in F. L∞ is the admissible heuristic with eight neighbors.
