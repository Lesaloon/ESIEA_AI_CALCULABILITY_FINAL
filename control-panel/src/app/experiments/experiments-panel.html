Fixed solution → variable configurations

Generalization

{{ transferBusy() ? 'Running…' : transfer() ? 'Done' : 'Ready' }}

Take the (heuristic, w) found by an optimizer on one configuration and test it on other maps. On each map the score is the optimizer's score: importance-weighted cost, time and memory, each divided by classic A* (L∞, w = 1) on that map — with importances 1/1/1 classic A* scores about 3, lower is better. Four strategies are compared: the fixed solution, classic A*, one robust pair chosen for the best mean score over all these maps, and a grid search re-tuned on every map (best possible on the grid, but costly).
